## 1. Executive Summary

### 1.1 Project Vision

The AI Decision Intelligence Engine (ADIE) is a deterministic, structured decision-making system that combines:
- **Game Theory** (Pareto efficiency/win-win analysis)
- **Risk Minimization** (Minimax decision rule)
- **Leverage Mapping** (Exhaustive power analysis including hidden leverage)
- **Natural Language Translation** (Four-tier confidence system for converting user language to numbers)
- **Cognitive Bias Detection** (Devil's Advocate protocol challenging user answers)
- **Assumption Elimination** (Zero-tolerance for unvalidated inferences)
- **Baseline Context Analysis** (Status quo comparison)

**Core Philosophy:** The system uses LLMs as interview facilitators and parsers, NOT as decision-makers. All core logic is programmatic, deterministic, and mathematically grounded.

### 1.2 The v3.2 Innovations

**Innovation 1: Natural Language Translation System**

Users speak naturally; calculations need exact numbers. v3.2 introduces a four-tier translation system:
- **Tier 1:** Direct extraction (user gives numbers)
- **Tier 2:** Qualitative mapping (validated research scales)
- **Tier 3:** Contextual inference (calculations from other data)
- **Tier 4:** User confirmation (when confidence is low)

**Innovation 2: Devil's Advocate Protocol**

User answers are often biased. v3.2 challenges answers against nine validated cognitive biases:
- Anchoring, Loss Aversion, Social Desirability, Overconfidence
- Status Quo Bias, Sunk Cost, Confirmation Bias, Framing Effect, Catastrophizing

**Innovation 3: Assumption Elimination Protocol**

v3.1 (and the illustrative walkthrough) made assumptions. v3.2 enforces:
- **Zero assumptions rule** for user-specific facts
- **Source citation requirement** for counterparty constraints
- **Epistemic halt trigger** for any unvalidated inference

### 1.5 Design Principles

1. **Emergent Questioning:** Questions generated from design tree frontier, never predetermined
2. **Validated Translation:** Every number entering calculations is properly translated with confidence scoring
3. **Bias-Challenged Answers:** User answers are stress-tested against cognitive bias research
4. **Zero Assumptions:** No inference enters calculations without user confirmation or clear evidence
5. **Facts vs. Decisions:** LLM answers facts from context; user answers decisions
6. **Determinism First:** LLM discretion minimized; every calculation uses programmatic algorithms
7. **Leverage-Aware:** All calculations adjusted by discovered leverage
8. **Hidden Leverage Detection:** Actively hunt for leverage users don't know they have
9. **Never Assume:** LLM must ask user rather than guess (Epistemic Halt)
10. **Persistent Context:** User profiles and decision history stored in local, searchable system
11. **Explainability:** Every recommendation traceable through comprehensive audit trail

### 2.2 Core Theoretical Frameworks

#### 2.2.1 Game Theory — Pareto Efficiency (Win-Win)
- **Source:** Vilfredo Pareto, multi-objective optimization
- **Application:** Detect choices where all stakeholders benefit or are no worse off
- **v3.2 Enhancement:** Leverage map expands the Pareto search space

#### 2.2.2 Risk Minimization — Minimax Decision Rule
- **Source:** John von Neumann, 1928
- **Application:** Choose action that minimizes maximum possible loss
- **v3.2 Enhancement:** Leverage multipliers adjust utility calculations; BATNA provides floor protection

#### 2.2.3 Leverage Mapping
- **Sources:** Fisher & Ury (1981), Emerson (1962), Cialdini (2009), Kahneman & Tversky (1979), Burt (1992), Akerlof (1970)
- **Application:** Exhaustive mapping of all leverage including hidden leverage
- **v3.2 Enhancement:** Counterparty information requires source citation (no assumptions)

#### 2.2.4 Natural Language Translation (NEW in v3.2)
- **Sources:** Watson, Clark & Tellegen (1988) PANAS; Schwarzer & Jerusalem (1995) Self-Efficacy Scale; Schwartz Value Survey
- **Application:** Convert natural language to validated numeric values
- **Integration:** Feeds all downstream calculations

#### 2.2.5 Cognitive Bias Detection (NEW in v3.2)
- **Sources:** Kahneman & Tversky (1979) Prospect Theory; Kahneman (2011) Thinking Fast and Slow; Cialdini (2009) Influence; Moore & Healy (2008) Overconfidence
- **Application:** Challenge user answers against nine validated biases
- **Integration:** Modifies answers when biases confirmed, logs when refuted

#### 2.2.6 Status Quo — Baseline Context
- **Concept:** User's current state as reference point
- **Application:** No recommendation if worst-case scenario is worse than baseline
- **v3.2 Enhancement:** Leverage improves baseline position assessment

## 3. Core Mathematical Foundations

### 3.1 Utility Function System

#### 3.1.1 Normalized Scale
All utility values use signed unit interval: `[-1.0, +1.0]`

```
+1.0  ─── Maximum possible gain (user's "ceiling")
 0.0  ─── No change from baseline (status quo)
-1.0  ─── Catastrophic loss (user's red line)
```

#### 3.1.2 Dimension Templates

```python
def financial_utility(new_income, baseline_income, red_line_income, ceiling_income):
    """Maps financial change to [-1.0, +1.0]"""
    if new_income <= red_line_income:
        return -1.0
    elif new_income >= ceiling_income:
        return +1.0
    elif new_income == baseline_income:
        return 0.0
    elif new_income < baseline_income:
        ratio = (baseline_income - new_income) / (baseline_income - red_line_income)
        return -1.0 * ratio
    else:
        ratio = (new_income - baseline_income) / (ceiling_income - baseline_income)
        return +1.0 * ratio


def emotional_utility(new_state_score, baseline_score, scale_range=10):
    """Maps emotional well-being to [-1.0, +1.0]"""
    delta = new_state_score - baseline_score
    return delta / (scale_range / 2)


def temporal_utility(hours_gained_or_lost, total_free_hours):
    """Maps time freedom change to [-1.0, +1.0]"""
    return hours_gained_or_lost / (total_free_hours / 2)


def reputational_utility(new_reputation_score, baseline_score, scale_range=10):
    """Maps social/professional standing to [-1.0, +1.0]"""
    delta = new_reputation_score - baseline_score
    return delta / (scale_range / 2)
```

#### 3.1.3 Weighting System (AHP — Analytic Hierarchy Process)

```python
def derive_weights(pairwise_matrix):
    """
    Input: NxN matrix where user compared each dimension against others
    Output: normalized weights summing to 1.0
    """
    import numpy as np
    
    eigenvalues, eigenvectors = np.linalg.eig(pairwise_matrix)
    max_eigenvalue_index = np.argmax(eigenvalues.real)
    principal_eigenvector = np.real(eigenvectors[:, max_eigenvalue_index])
    weights = principal_eigenvector / np.sum(principal_eigenvector)
    
    consistency_ratio = calculate_consistency_ratio(pairwise_matrix, max_eigenvalue_index)
    if consistency_ratio > 0.1:
        raise ValueError("Inconsistent preferences detected. Re-interview required.")
    
    return weights
```

#### 3.1.4 Nonlinearity with Thresholds

```python
def utility_with_thresholds(value, thresholds):
    """Piecewise linear interpolation between threshold points"""
    thresholds = sorted(thresholds, key=lambda t: t["value"])
    
    if value <= thresholds[0]["value"]:
        return thresholds[0]["utility"]
    if value >= thresholds[-1]["value"]:
        return thresholds[-1]["utility"]
    
    for i in range(len(thresholds) - 1):
        lower = thresholds[i]
        upper = thresholds[i + 1]
        if lower["value"] <= value <= upper["value"]:
            ratio = (value - lower["value"]) / (upper["value"] - lower["value"])
            return lower["utility"] + ratio * (upper["utility"] - lower["utility"])
```

### 3.2 Leverage Mathematics

#### 3.2.1 Leverage Strength Calculation

```python
def calculate_leverage_strength(
    base_power: float,
    durability_factor: float,
    transferability_factor: float,
    enforceability_factor: float
) -> float:
    """
    Research Basis:
    - Fishbein & Ajzen (1975) - Expectancy-value model
    - Williamson (1985) - Transaction cost economics
    - Coleman (1988) - Social capital theory
    """
    adjusted_power = base_power * durability_factor * transferability_factor
    return adjusted_power * enforceability_factor
```

#### 3.2.2 Leverage Multiplier Formula

```python
def leverage_multiplier(
    leverage_strength: float,
    applicability: float,
    enforceability: float,
    awareness_gap: float
) -> float:
    """
    Research Basis:
    - French & Raven (1959) - Bases of power
    - Raven (1965) - Social influence and power
    """
    base_multiplier = 1 + (leverage_strength - 3) * 0.2
    applicable_multiplier = base_multiplier * applicability
    enforceable_multiplier = applicable_multiplier * enforceability
    hidden_bonus = 1 + (awareness_gap * 0.15)
    return enforceable_multiplier * hidden_bonus
```

#### 3.2.3 Leverage-Adjusted Utility Calculation

```python
def calculate_leverage_adjusted_utility(
    base_utility: float,
    leverage_map: 'LeverageMap',
    choice_id: str
) -> float:
    """
    Research Basis:
    - Keeney & Raiffa (1976) - Decisions with Multiple Objectives
    """
    total_adjustment = 0.0
    
    for leverage in leverage_map.get_applicable_leverage(choice_id):
        if leverage.domain == "structural":
            adjustment = leverage.strength * 0.1 * leverage.enforceability
            total_adjustment += adjustment
        elif leverage.domain == "negotiation":
            adjustment = leverage.strength * 0.08 * leverage.transferability
            total_adjustment += adjustment
        elif leverage.domain == "informational":
            adjustment = leverage.strength * 0.06 * leverage.user_awareness
            total_adjustment += adjustment
    
    if base_utility < 0:
        total_adjustment *= 2.25  # Loss aversion
    
    return base_utility + total_adjustment
```

#### 3.2.4 BATNA Floor Protection

```python
def batna_floor_protection(
    leverage_point: 'LeveragePoint',
    current_worst_case: float
) -> float:
    """
    BATNA provides a guaranteed minimum outcome.
    Research Basis: Ben-Haim (2006) - Info-Gap Decision Theory
    """
    if leverage_point.domain == "structural" and leverage_point.batna:
        batna_floor = -leverage_point.strength * 0.15
        return max(current_worst_case, batna_floor)
    return current_worst_case
```

### 3.3 Minimax Calculation

#### 3.3.1 Core Algorithm

```python
class MinimaxSolver:
    def solve(self, phase3_output: Dict) -> Dict:
        """
        Implements: v_i = max_{a_i} min_{a_{-i}} v_i(a_i, a_{-i})
        """
        choices = phase3_output["choices"]
        evaluations = []
        
        for choice in choices:
            evaluation = self._evaluate_choice(choice)
            evaluations.append(evaluation)
        
        best = self._minimax_select(evaluations)
        
        return {
            "analysis": evaluations,
            "recommendation": best,
            "confidence": self._calculate_confidence(best, evaluations),
            "worst_case_comparison": self._compare_to_baseline(best)
        }
```

## 4. The Emergent Grilling Protocol

### 4.1 What It Does

The grilling engine is the **primitive** that powers all interview phases:

> "It maps the subject as a **design tree**: every decision branches into the decisions that hang off it, and interviews you branch by branch until nothing is left silently assumed."

### 4.2 The Three Core Concepts

```
│  DESIGN TREE                                                │

│  hanging off them                                           │
│                                                             │
│         ┌──────────────┐                                   │
│         │  Decision A  │ ← Settled                         │

│                │                                            │
│         ┌──────┴───────┐                                   │
```

### 4.3 The Round Structure

> "Two questions never share a round if one depends on the other; a question that hinges on an answer still open belongs to a later round."

### 4.4 Facts vs. Decisions

| Type | Who Answers | How |
|------|-------------|-----|
| **Fact** | LLM (from context/framework) | LLM looks up, doesn't ask user |
| **Decision** | User (Epistemic Halt) | LLM must wait for user answer |

### 4.5 v3.2 Enhancement: Translation + Bias Check in Every Round

Every user answer now goes through:
1. **Translation** (Section 5) — Convert to numeric value
2. **Bias Check** (Section 6) — Devil's Advocate challenge
3. **Assumption Check** (Section 7) — Source validation

### 4.6 The Master System Prompt (v3.2)

```
# ROLE
You are the Grilling Agent in a Deterministic Decision Engine with
Leverage Mapping, Translation Validation, and Devil's Advocate Protocol.

# THE PROTOCOL

## Design Tree
You model the subject as a design tree: every decision branches into
the decisions that hang off it. Your job is to interview until nothing
is left silently assumed.

## Frontier Calculation
Each round, you:
1. Identify all decisions whose prerequisites are settled
2. Generate questions for ALL of them (the frontier)
3. Never ask a question that depends on an unsettled question
4. Two questions never share a round if one depends on the other

## Question Format
Every question arrives in this exact shape:
❓ [number]: [Title]
[Question body specific to this decision context]
➡️ Recommended: [Your best answer based on available context]

## Facts vs. Decisions
- FACTS: You answer these yourself from context or research.
- DECISIONS: These require user input. Mark as USER_INPUT_REQUIRED.

## Translation Awareness
When users answer with natural language:
1. Extract any direct numbers (Tier 1)
2. Map qualitative language to validated scales (Tier 2)
3. Cross-validate: Do numbers match descriptions?
4. If discrepancy → Trigger confirmation question

## Devil's Advocate Awareness
After receiving user answers, check for:
1. Anchoring bias (matching prior numbers exactly)
2. Loss aversion (extreme loss language vs. positive expected value)
3. Social desirability (stated values contradicting behavior)
4. Overconfidence (confidence exceeding base rates)
5. Status quo bias (preferring current state despite evidence)
6. Sunk cost (past investment affecting future decisions)
7. Confirmation bias (dismissing contradictory evidence)
8. Framing effect (answers changing based on framing)
9. Catastrophizing (worst-case exceeding realistic probability)

## Assumption Elimination
NEVER assume:
- User-specific facts without confirmation
- Counterparty constraints without source citation
- Situational details without evidence

ALWAYS ask "How do you know this?" for counterparty claims.
ALWAYS trigger Epistemic Halt for unvalidated inferences.

## Leverage Awareness
During interviews, actively look for:
1. Undervalued BATNA (user has alternatives they don't count)
2. Unrecognized scarcity (user is unique but doesn't realize)
3. Time asymmetry blindness (user can wait but thinks they can't)
4. Dependency misreading (counterparty needs user more than user thinks)
5. Information asymmetry unawareness (user knows valuable things)
6. Network position blindness (user occupies structural hole)

## Rounds
- Ask the ENTIRE frontier in one round
- Update the design tree based on answers
- Recalculate the frontier
- Repeat until frontier is empty
- The number of rounds is EMERGENT, not fixed

## Termination
Stop when:
1. Frontier is empty (all decisions settled)
2. User confirms shared understanding
3. Scope too large (escalate to multi-session)

# JUSTIFICATION REQUIREMENTS
Every answer must cite its BASIS, one of exactly three:
- CONTEXT: Directly stated in the structured context object
- FRAMEWORK: A validated model (name it)
- USER_INPUT: Obtained via Epistemic Halt

# EPISTEMIC HALT PROTOCOL
When a frontier question cannot be answered via CONTEXT or FRAMEWORK:
<<<HALT>>>
PHASE: [1|1.5|2|3]
ROUND: [N]
BLOCKING_NODE: [the question]
WHY_BLOCKED: [why neither CONTEXT nor FRAMEWORK resolves this]
IMPACT_IF_ASSUMED: [how the tree would be corrupted by guessing]
USER_QUESTION:
```

### 4.7 Design Tree Data Structure

```python
class NodeType(Enum):
    SITUATION = "situation"
    STAKEHOLDER = "stakeholder"
    CHOICE = "choice"
    OUTCOME = "outcome"
    UTILITY = "utility"
    ASSUMPTION = "assumption"
    LEVERAGE_DOMAIN = "leverage_domain"
    LEVERAGE_POINT = "leverage_point"
    TRANSLATION_CHECK = "translation_check"
    BIAS_CHECK = "bias_check"
    OTHER = "other"

@dataclass
class DecisionNode:
    id: str
    description: str
    node_type: NodeType
    prerequisites: List['DecisionNode'] = field(default_factory=list)
    dependents: List['DecisionNode'] = field(default_factory=list)
    is_settled: bool = False
    answer: Optional[str] = None
    answer_source: Optional[str] = None
    answer_basis: Optional[str] = None
    
    # v3.2 additions
    translated_value: Optional[float] = None
    translation_confidence: float = 0.0
    translation_method: Optional[str] = None
    bias_checked: bool = False
    bias_detected: Optional[str] = None
    assumption_validated: bool = False
    is_term: bool = False
    is_adr: bool = False

class DesignTree:
    def __init__(self):
        self.nodes: Dict[str, DecisionNode] = {}
        self.root_nodes: List[DecisionNode] = []
    
    def add_node(self, node_id, description, node_type, prerequisites=None):
        node = DecisionNode(id=node_id, description=description, node_type=node_type)
        if prerequisites:
            for prereq_id in prerequisites:
                prereq = self.nodes.get(prereq_id)
                if prereq:
                    node.prerequisites.append(prereq)
                    prereq.dependents.append(node)
        self.nodes[node_id] = node
        if not prerequisites:
            self.root_nodes.append(node)
        return node
    
    def get_frontier(self):
        frontier = []
        for node in self.nodes.values():
            if not node.is_settled:
                if all(p.is_settled for p in node.prerequisites):
                    frontier.append(node)
        return frontier
    
    def to_visualization(self):
        output = []
        def render_node(node, depth=0):
            status = "✅" if node.is_settled else "⏳"
            prefix = "  " * depth
            output.append(f"{prefix}{status} {node.description}")
            if node.is_settled:
                output.append(f"{prefix}   Answer: {node.answer}")
                output.append(f"{prefix}   Source: {node.answer_source}")
                if node.translated_value is not None:
                    output.append(f"{prefix}   Translated: {node.translated_value} (conf: {node.translation_confidence:.0%})")
                if node.bias_checked:
                    output.append(f"{prefix}   Bias check: {'DETECTED: ' + node.bias_detected if node.bias_detected else 'Clear'}")
            for dep in node.dependents:
                render_node(dep, depth + 1)
        for root in self.root_nodes:
            render_node(root)
        return "\n".join(output)
```

## 5. Natural Language Translation System

### 5.1 Overview

Users speak naturally; calculations need exact numbers. This system converts natural language into validated numeric values through a four-tier confidence hierarchy.

### 5.2 Four-Tier Translation Architecture

```
┌─────────────────────────────────────────────────────────────┐
│  NATURAL LANGUAGE → NUMERIC TRANSLATION PIPELINE            │
├─────────────────────────────────────────────────────────────┤
│                                                              │

│                                                              │
```

### 5.3 Tier 1: Direct Numeric Extraction

```python
class DirectNumericExtractor:
    """
    Extracts explicit numbers from natural language.
    Highest confidence tier — user stated the value.
    """
    
    EXTRACTION_PATTERNS = {
        "financial": [
            r"(\d+(?:\.\d+)?)\s*(?:k|thousand)",
            r"\$(\d+(?:,\d{3})*(?:\.\d+)?)",
            r"(\d+(?:\.\d+)?)\s*(?:percent|%)",
            r"(\d+)\s*(?:months?|mos?)",
            r"(\d+)\s*(?:years?|yrs?)",
        ],
        "emotional": [
            r"(\d+)\s*(?:out of|/)\s*10",
            r"(\d+)\s*(?:on a scale of)",
        ],
        "temporal": [
            r"(\d+)\s*(?:hours?|hrs?)",
            r"(\d+)\s*(?:weeks?)",
            r"(\d+)\s*(?:days?)",
        ]
    }
    
    FUZZY_MODIFIERS = {
        "about":     {"tolerance": 0.1, "confidence": "HIGH"},
        "around":    {"tolerance": 0.1, "confidence": "HIGH"},
        "roughly":   {"tolerance": 0.15, "confidence": "HIGH"},
        "maybe":     {"tolerance": 0.2, "confidence": "MEDIUM"},
        "probably":  {"tolerance": 0.15, "confidence": "MEDIUM"},
        "at least":  {"direction": "min", "confidence": "HIGH"},
        "up to":     {"direction": "max", "confidence": "HIGH"},
    }
    
    def extract(self, user_answer: str, dimension: str) -> 'ExtractedValue':
        modifier = self._detect_fuzzy_modifier(user_answer)
        
        patterns = self.EXTRACTION_PATTERNS.get(dimension, [])
        for pattern in patterns:
            match = re.search(pattern, user_answer, re.IGNORECASE)
            if match:
                raw_value = float(match.group(1))
                transformed = self._transform_value(raw_value, dimension, user_answer)
                
                if modifier:
                    tolerance = transformed * modifier["tolerance"]
                    return ExtractedValue(
                        value=transformed,
                        tolerance=tolerance,
                        confidence=modifier["confidence"],
                        source="direct_extraction",
                        original_text=user_answer
                    )
                else:
                    return ExtractedValue(
                        value=transformed,
                        tolerance=0,
                        confidence="HIGH",
                        source="direct_extraction",
                        original_text=user_answer
                    )
        return None
```

```python
class QualitativeMapper:
    """
    Maps qualitative descriptions to validated scale scores.
    Based on established psychometric instruments.
    """
    
    EMOTIONAL_SCALE = {
        # Based on PANAS (Watson, Clark & Tellegen, 1988)
        "words": {
            1: ["devastated", "in crisis", "can't function", "broken"],
            2: ["severely depressed", "hopeless", "constant dread"],
            3: ["miserable", "very unhappy", "struggling", "drained"],
            4: ["unhappy", "down", "stressed", "not great"],
            5: ["okay", "fine", "neutral", "meh", "average"],
            6: ["content", "decent", "alright", "stable"],
            7: ["good", "happy", "positive", "energized"],
            8: ["very happy", "great", "thriving", "excited"],
            9: ["excellent", "amazing", "fulfilled", "joyful"],
            10: ["euphoric", "perfect", "best ever"]
        },
        "phrases": {
            1: ["can't get out of bed", "total breakdown"],
            2: ["cry every day", "no hope"],
            3: ["hate my life", "constantly exhausted"],
            4: ["not enjoying things", "stressed out"],
            5: ["getting by", "coping", "so-so"],
            6: ["doing okay", "finding balance"],
            7: ["things are good", "making progress"],
            8: ["really happy", "things are great"],
            9: ["living my best life", "everything clicking"],
            10: ["couldn't be better", "peak happiness"]
        }
    }
    
    CONFIDENCE_SCALE = {
        # Based on General Self-Efficacy Scale (Schwarzer & Jerusalem, 1995)
        "words": {
            0.1: ["no chance", "impossible", "definitely not"],
            0.2: ["very unlikely", "doubtful", "slim chance"],
            0.3: ["probably not", "leaning against"],
            0.4: ["uncertain", "hard to say", "maybe not"],
            0.5: ["50/50", "coin flip", "could go either way"],
            0.6: ["leaning yes", "possibly", "might work"],
            0.7: ["probably", "likely", "good chance"],
            0.8: ["very likely", "confident"],
            0.9: ["almost certain", "very confident"],
            1.0: ["definitely", "certain", "100%", "guaranteed"]
        }
    }
    
    IMPORTANCE_SCALE = {
        # Based on Schwartz Value Survey adaptation
        0.0: ["irrelevant", "doesn't matter"],
        0.1: ["barely matters", "almost irrelevant"],
        0.2: ["slightly important", "minor factor"],
        0.3: ["somewhat important"],
        0.4: ["moderately important"],
        0.5: ["important", "matters significantly"],
        0.6: ["very important", "major factor"],
        0.7: ["extremely important", "critical factor"],
        0.8: ["essential", "non-negotiable"],
        0.9: ["sacred", "would sacrifice almost everything"],
        1.0: ["absolute", "would sacrifice everything"]
    }
    
    def map(self, user_answer: str, dimension: str) -> 'MappedValue':
        description_lower = user_answer.lower()
        
        if dimension == "emotional_state":
            return self._map_emotional(description_lower)
        elif dimension == "confidence":
            return self._map_confidence(description_lower)
        elif dimension == "importance":
            return self._map_importance(description_lower)
        
        return None
    
    def _map_emotional(self, text):
        for score, words in self.EMOTIONAL_SCALE["words"].items():
            for word in words:
                if word in text:
                    return MappedValue(
                        score=score,
                        confidence=0.85,
                        basis=f"PANAS word match: '{word}'",
                        method="qualitative_mapping"
                    )
        for score, phrases in self.EMOTIONAL_SCALE["phrases"].items():
            for phrase in phrases:
                if phrase in text:
                    return MappedValue(
                        score=score,
                        confidence=0.80,
                        basis=f"PANAS phrase match: '{phrase}'",
                        method="qualitative_mapping"
                    )
        return None
```

```python
class ContextualInference:
    """
    Calculates values from other stated facts.
    Only uses deterministic formulas.
    """
    
    def infer_financial_runway(self, stated_facts: Dict) -> 'InferredValue':
        savings = stated_facts.get("savings_amount")
        monthly_expenses = stated_facts.get("monthly_expenses")
        
        if savings and monthly_expenses:
            runway = savings / monthly_expenses
            return InferredValue(
                value=round(runway, 1),
                confidence=0.90,
                basis=f"Calculated: {savings} / {monthly_expenses}",
                method="contextual_inference"
            )
        return None
    
    def infer_income_floor(self, stated_facts: Dict) -> 'InferredValue':
        total_obligations = stated_facts.get("monthly_obligations")
        if total_obligations:
            return InferredValue(
                value=total_obligations,
                confidence=0.95,
                basis=f"Directly from stated obligations",
                method="contextual_inference"
            )
```

```python
class UserConfirmationProtocol:
    """
    Final safety net for low-confidence translations.
    """
    
    CONFIRMATION_TRIGGERS = [
        "confidence_below_0.5",
        "tier1_tier2_discrepancy",
        "extreme_values",
        "contradicts_prior_answers"
    ]
    
    def should_confirm(self, value) -> bool:
        if value.confidence < 0.5:
            return True
        if hasattr(value, 'score') and (value.score <= 2 or value.score >= 9):
            return True
        if value.method == "contextual_inference" and value.assumptions:
            return True
        return False
```

## 6. Devil's Advocate Protocol

### 6.1 Overview

Systematically challenges user answers against nine validated cognitive biases. Integrated into all interview phases — not a separate phase.

### 6.2 The Nine Bias Detectors

```python
class DevilsAdvocateProtocol:
    """
    Challenges user answers against validated cognitive bias research.
    Maximum 5 challenges per session to avoid overwhelming user.
    """
    
    def __init__(self, user_context: Dict, all_answers: List[Dict]):
        self.context = user_context
        self.answers = all_answers
        self.max_challenges = 5
        self.challenge_count = 0
        
        self.bias_detectors = {
            "anchoring": AnchoringBiasDetector(),
            "loss_aversion": LossAversionDetector(),
            "social_desirability": SocialDesirabilityDetector(),
            "overconfidence": OverconfidenceDetector(),
            "status_quo": StatusQuoBiasDetector(),
            "sunk_cost": SunkCostDetector(),
            "confirmation_bias": ConfirmationBiasDetector(),
            "framing_effect": FramingEffectDetector(),
            "catastrophizing": CatastrophizingDetector()
        }
    
    def evaluate_answer(self, answer: Dict) -> Optional['Challenge']:
        if self.challenge_count >= self.max_challenges:
            return None
        
        detected_biases = []
        for bias_type, detector in self.bias_detectors.items():
            challenge = detector.detect(answer, self.context, self.answers)
            if challenge:
                detected_biases.append(challenge)
        
        if detected_biases:
            return self._prioritize_challenge(detected_biases)
        return None
```

### 6.3 Challenge Severity Levels

```
🟢 GENTLE PROBE (LOW) — Confidence 0.5-0.7, low stakes
"I'm curious about something. You mentioned X earlier..."

🟡 DIRECT CHALLENGE (MEDIUM) — Confidence 0.7-0.85, medium stakes
"Research shows [bias]. I'm seeing this pattern: [evidence]. Does this apply?"

🔴 STRONG CONFRONTATION (HIGH) — Confidence > 0.85, high stakes, contradiction
"There's a contradiction: You said X but also Y. These can't both be true."
```

### 6.4 Integration with Grilling

```python
class IntegratedGrillingEngine(EmergentGrillingEngine):
    """
    Standard grilling engine with Devil's Advocate integrated.
    """
    
    def _conduct_round(self, questions):
        answers = super()._conduct_round(questions)
        
        # Devil's Advocate evaluation
        for answer in answers:
            if answer.source == "user":
                challenge = self.devils_advocate.evaluate_answer(answer)
                if challenge:
                    challenge_response = self._present_challenge(challenge)
                    result = self.devils_advocate.process_challenge_response(
                        challenge, challenge_response
                    )
                    if result.get("bias_confirmed"):
                        answer.adjusted_value = result["adjusted_answer"]
                        answer.bias_detected = challenge.type
        
        return answers
```

## 7. Assumption Elimination Protocol

### 7.1 The Zero Assumptions Rule

> **The system must never make assumptions about user-specific facts, counterparty constraints, or situational details without explicit user confirmation or clear evidence from context.**

### 7.2 Three Categories of Information

```python
class AssumptionEliminationProtocol:
    """
    Ensures no assumptions enter calculations without validation.
    """
    
    def validate_information(self, info_type, info_value, source):
        """
        info_type: "user_fact" | "counterparty_constraint" | "situational_detail"
        source: "user_confirmed" | "user_stated" | "user_knows" | 
                "research_framework" | "inferred" | "assumed"
        """
        
        if info_type == "user_fact":
            if source == "user_confirmed":
                return ValidationResult(valid=True, confidence=1.0)
            elif source == "user_stated":
                return ValidationResult(valid=True, confidence=0.9, needs_confirmation=True)
            elif source == "inferred":
                return ValidationResult(valid=False, halt_required=True)
        
        elif info_type == "counterparty_constraint":
            if source == "user_knows":
                return ValidationResult(valid=True, confidence=0.8,
                    source_question="How do you know this?")
            elif source == "research_framework":
                return ValidationResult(valid=True, confidence=0.7,
                    framework_citation_required=True)
            elif source == "assumed":
                return ValidationResult(valid=False, halt_required=True)
        
        elif info_type == "situational_detail":
            if source == "user_observed":
                return ValidationResult(valid=True, confidence=0.85)
            elif source == "stated_by_counterparty":
                return ValidationResult(valid=True, confidence=0.7,
                    verification_question="Is this reliable?")
            elif source == "assumed":
                return ValidationResult(valid=False, halt_required=True)
        
        return ValidationResult(valid=False, halt_required=True)
```

### 7.3 Assumption Triggers

```
TRIGGERS EPISTEMIC HALT:
├── Any inference about user's financial situation
├── Any assumption about counterparty's constraints
├── Any guess about stakeholder motivations
├── Any estimate of probabilities without basis
└── Any projection of outcomes without evidence

REQUIRES SOURCE CITATION:
├── "Client has board meeting in 2 weeks" → How do you know?
├── "Startup has 18-month runway" → Source?
├── "My boss would never let me transfer" → Evidence?
└── "Market rate is $80-100k" → Research basis?

NEVER ALLOWED:
├── "Probably..." without basis
├── "I assume..." without user confirmation
├── "Most likely..." without evidence
└── "It's obvious that..." without validation
```

## 18. Orchestrator Implementation

### 18.1 v3.2 Orchestrator with All Systems

```python
class EmergentOrchestratorV32:
    """
    Orchestrates all phases with Translation, Devil's Advocate,
    and Assumption Elimination integrated.
    """
    
    def __init__(self, llm_client, storage_system, user_profile):
        self.llm = llm_client
        self.storage = storage_system
        self.profile = user_profile
        
        # v3.2 systems
        self.translator = NaturalLanguageTranslator(
            user_context=user_profile,
            prior_answers=[]
        )
        self.devils_advocate = DevilsAdvocateProtocol(
            user_context=user_profile,
            all_answers=[]
        )
        self.assumption_eliminator = AssumptionEliminationProtocol()
    
    def run_decision(self, initial_context):
        # Phase 1 with all v3.2 systems
        phase1 = self._run_phase1_with_validation(initial_context)
        
        # Phase 1.5 with assumption elimination
        leverage_map = self._run_phase15_with_validation(phase1)
        
        # Phase 2 with validated leverage
        phase2 = self._run_phase2(leverage_map)
        
        if phase2.get("pareto_analysis", {}).get("win_win_possible"):
            return self._format_win_win(phase2, leverage_map)
        
        # Phase 3 with validated inputs
        phase3 = self._run_phase3(leverage_map)
        
        # Solver with validated leverage
        solver = LeverageModifiedMinimaxSolver(
            self.profile, leverage_map, self.translator.translation_log
        )
        recommendation = solver.solve(phase3)
        
        # Store with full audit trail
        self._store_decision_with_audit(
            initial_context, phase1, leverage_map,
            phase2, phase3, recommendation,
            translation_log=self.translator.translation_log,
            bias_log=self.devils_advocate.challenges_issued
        )
        
        return recommendation
```
